## Selected Projects

### [Large-Step Gradient Descent](https://github.com/Derrick2007/large-step-gd-reproduction)

A NumPy reproduction of selected experiments from
Shuang Liang and Guido Montúfar's work on chaos and
fractal convergence regions in gradient descent.

Includes reproducible experiments, numerical diagnostics,
mathematical tests, and educational code guides.

### [Stochastic Simulation & Computational Finance](https://github.com/Derrick2007/stoch-finance)

An ongoing project exploring Monte Carlo methods for
option pricing and numerical uncertainty.

Currently includes exact geometric Brownian motion sampling,
Black–Scholes validation, and repeated experiments to assess
estimation error and confidence intervals.

### [MyUCLA Workspace](https://github.com/comet-ctrl/myucla-workspace)

I contribute interface improvements and fixes to a browser
extension for the MyUCLA Class Planner.
